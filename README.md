# Социальная сеть — Frontend

Клиентская часть социальной сети. Реализована на **React 19** со сборщиком **Vite** и взаимодействует с бэкендом на **Spring Boot** через REST API.

---

## О проекте

Клиент-серверное приложение с разделением на бэкенд (Spring Boot) и фронтенд (React). Реализована ролевая модель доступа с двумя ролями — **пользователь** и **администратор**.

### Возможности роли «Пользователь»

- управление собственными постами (создание, редактирование, удаление);
- просмотр постов других пользователей;
- управление подписками и просмотр списка подписчиков;
- личные сообщения: переписка с пользователями, управление чатами и сообщениями.

### Возможности роли «Администратор»

- все права пользователя;
- управление пользователями;
- управление постами всех пользователей.

---

## Технологический стек

- **JavaScript** — язык разработки;
- **React 19** — библиотека для построения интерфейса;
- **React Router 7** — маршрутизация;
- **React Bootstrap + Bootstrap 5** — UI-компоненты и стилизация;
- **Bootstrap Icons / React Bootstrap Icons** — иконки;
- **React Responsive** — адаптивность интерфейса под разные экраны;
- **Vite** — сборщик и dev-сервер;
- **ESLint + Prettier** — линтинг и форматирование кода.

## Запуск проекта

### Требования

- Node.js (LTS-версия)
- npm
- Запущенный бэкенд (Spring Boot) — репозиторий: [ссылка на бэкенд](https://github.com/Anitonchik/IP_SocialNetwork_Backend)

### Установка и запуск в режиме разработки

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Anitonchik/IP_SocialNetwork_Frontend
cd IP_SocialNetwork_Frontend

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер Vite
npm start
```

Dev-сервер Vite поднимется на **http://localhost:8000** (порт задан в скрипте `start`).

### Сборка и запуск production-версии

```bash
# Собрать проект (результат в папке dist/)
npm run build

# Собрать и сразу раздать через http-server
npm run prod
```

Либо отдельно:

```bash
npm run build   # сборка в dist/
```

### Линтинг

```bash
npm run lint
```

## Скрипты

| Команда         | Действие                                              |
|-----------------|-------------------------------------------------------|
| `npm start`     | запуск dev-сервера Vite на порту 8000                 |
| `npm run build` | сборка production-версии в `dist/`                    |
| `npm run prod`  | сборка + раздача (`build` + `serve`)                  |
| `npm run lint`  | проверка кода ESLint                                  |
